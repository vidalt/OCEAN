Constraint Programming Backend
==============================

The :mod:`ocean.cp` module exposes the OR-Tools CP-SAT formulation. In
addition to the standard counterfactual search API, the public explainer also
accepts an optional ``IsolationForest`` through ``isolation=...`` when you
want to add the same plausibility constraint available in the MIP backend.
