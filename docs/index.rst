OCEAN Documentation
===================

OCEAN provides exact counterfactual explanations for tree ensembles through
three interchangeable optimization backends: mixed-integer programming,
constraint programming, and weighted MaxSAT.

The guide below starts with the common workflow, then goes deeper into data
preparation, backend-specific behavior, and worked examples.
